### 🧠 About Me

Quiet nights, loud mind, broken dreams.  Trying to build things that work when nothing else seems to.  Somewhere between 3 AM thoughts and endless loops.  
Life didn't come with documentation, and it definitely has breaking bugs.  Writing scripts to solve problems I can control, because the ones in reality are too heavy to debug.  

`tired eyes // silent battles // noisy world`  

Trying to make sense of a world that rarely makes any.  Life is hard, days are long, and peace is expensive.  I don't have all the answers. Taking it one unresolved promise at a time.  Trying my best, failing anyway. Debugging code while life throws unhandled exceptions.  Surviving on coffee and silence.  
`Ctrl + Z` doesn’t work in real life and it shows.  Mentally exhausted, emotionally drained, but the code still compiles.
